# Kairon GUI Prototype V2

This version moves the central Core away from simple concentric circles and toward an
organic, neural/energy visual based on a generated transparent SVG plus animated QML layers.

Run:

    pip install PySide6
    python main.py

The bottom state strip is temporary development tooling. It will be removed after the
Core is connected to Kairon's real state manager.

Target visual direction:
- dark cinematic blue environment
- organic luminous neural Core
- moving internal light
- orbital energy field
- atmospheric particle field
- soft Core reflection
- right-side weather and transcript HUD

The next iteration should use custom GPU shader/particle rendering for finer filament
movement, bloom, distortion and speech-synchronized animation.
